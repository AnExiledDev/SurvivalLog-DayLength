# Changelog

## 0.3.4

- Clearer wording in the settings and on the Mods screen.
- The Mods screen no longer says days are twice as long by default. They keep their normal length until you set `DayLength`.
- Made for Survival Log 1.1.20719.

## 0.3.3

- Now needs Exiled's Toolkit 0.20.0 or newer.
- Made for Survival Log 1.1.20719.

## 0.3.2

- Some of its code now lives in Exiled's Toolkit, so it needs Exiled's Toolkit 0.19.0 or newer.
- Made for Survival Log 1.1.20719.

## 0.3.1

- Days now keep their normal length until you set `DayLength`, because its default is now 1. If you already set a value, it is kept.
- Made for Survival Log 1.1.20719.

## 0.3.0

- Each world can keep its own day length. With Exiled's Toolkit 0.17.0 or newer, pick it for a new world in Customizable Difficulty, or change it for the world you are playing on the Mod Manager's Mods screen. It takes effect the next time that world loads.
- Made for Survival Log 1.1.20151.

## 0.2.1

- After a game update, Mod Manager can tell you if this mod may need an update.
- Made for Survival Log 1.1.19131.

## 0.2.0

- Mod Manager's Mods screen links to this changelog.
- The day length can be changed on the Mod Manager's Mods screen without restarting the game. A new length takes effect the next time you load a save.
- Mod Manager's Mods screen shows the mod's name, description, category and links.
- Exiled's Toolkit 0.4.0 or newer is optional. With it, settings you change on the Mods screen take effect right away. Without it, they take effect the next time you start the game.

## 0.1.0

- First public release.
- Each in-game day lasts longer in real time, twice as long by default.
- Hunger, plant growth and disaster countdowns slow down to match, so a day still costs the same food.
